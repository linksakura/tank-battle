# 坦克大战 Battle City

一个用纯 HTML5 Canvas 实现的经典坦克大战游戏，单文件 `index.html`，无需任何依赖，双击即可游玩。

## 玩法

- 控制黄色坦克，守住底部的基地（鹰）不被敌人摧毁
- 消灭所有红色敌方坦克即可过关，每关敌人数量递增
- 基地被摧毁或生命耗尽则游戏结束

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动坦克 |
| 空格 / J | 发射炮弹 |
| P | 暂停 / 继续 |
| Enter | 开始 / 重新开始 |

手机端打开页面会自动显示虚拟方向键与开火按钮。

## 地图元素

- 🧱 砖墙：可被炮弹摧毁
- ⛓ 钢墙：无法摧毁
- 🪖 草丛：坦克可在下方穿行（会遮挡视线）
- 🦅 鹰（基地）：被击中即游戏结束

## 运行

直接用浏览器打开 `index.html`，或部署到 GitHub Pages：

1. 仓库 `Settings` → `Pages`
2. `Source` 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 技术要点

- 纯 Canvas 2D 渲染，13×13 瓦片地图
- 基于网格的 AABB 碰撞检测
- 敌人生成、简单 AI（随机转向 + 概率朝向玩家 + 冷却射击）
- 粒子爆炸效果与 Web Audio 音效
